# Consigne de voix de BeeDoo

Consigne donnée au modèle de synthèse vocale (`gpt-4o-mini-tts`), avec la voix `fable`.
Le nom doit être écrit « Bidou » dans le texte lu (voir `src/beedoo/voice/pronunciation.py`).
